# youtube-music-widget

YouTube Music을 위한 가벼운 데스크톱 래퍼 앱. `music.youtube.com`을 Electron 창 하나로 띄우고 편의 기능만 붙였습니다.

## 기능

- 트레이 아이콘: 창을 닫아도 백그라운드에서 계속 재생, 트레이 아이콘 클릭으로 창 보이기/숨기기
- 항상 위에 고정 옵션 (트레이 메뉴 체크박스)
- 로그인 세션 유지 (재시작해도 다시 로그인할 필요 없음)
- 창 위치/크기, 항상 위 고정 여부 자동 저장

## 실행

```bash
npm install
npm start
```
